ICS — End-to-End Process Flow

Intelligent Container Solutions · From port pull-out to empty return

CRO = Container Release Order · laden pull-out from port  |  eDO = Empty return  |  A product of TNSDS
flowchart TD
  START([START]) --> CRO[Shipping line issues CRO
Container Release Order]
  CRO --> PORT[Trucker pulls out laden container
from the PORT]
  PORT --> EDO[Shipping line issues eDO
Empty return]
  EDO --> PF[Trucker submits pre-forecast
+ photos + eDO]
  PF --> EVAL{Shipping line
evaluates}
  EVAL -->|Needs correction| COMP[For compliance]
  COMP --> PF
  EVAL -->|Approved| YARD[Assign CY / yard
+ schedule return slot]
  YARD --> FREE{Empty-return
free time still valid?}
  FREE -->|Expired| DEM[Demurrage / detention billing]
  DEM --> SETTLE{Charges settled
and verified?}
  SETTLE -->|No| DEM
  SETTLE -->|Yes| PAY
  FREE -->|Yes| PAY[Trucker pays return fees
uploads proof]
  PAY --> VER{ICS admin / shipping line
verifies payment}
  VER -->|Reject| PAY
  VER -->|Approve| QR[QR booking ready
for the gate]
  QR --> GATE[Trucker arrives at CY]
  GATE --> END([Empty returned · END])
